# AutoStart

Приложение для автомагнитолы на Android 9.

## Что делает
- После перезагрузки запускает выбранное приложение с задержкой 5 секунд.
- Позволяет выбрать приложение из списка установленных.
- Повторный тап по выбранному приложению снимает выбор.

## Установка
1. Скачать `app-debug.apk` из вкладки Actions → последний успешный билд → Artifacts.
2. Установить на магнитолу, разрешив «Установка из неизвестных источников».
3. Открыть приложение один раз, выбрать целевой лаунчер.
4. Разрешить автозапуск для AutoStart в настройках магнитолы.
5. Перезагрузить магнитолу.
